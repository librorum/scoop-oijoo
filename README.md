# Oijoo Scoop 버킷

[Oijoo](https://oijoo.com) — 외주 프로젝트 모아보기 · 입찰 도우미 (Windows)

```powershell
scoop bucket add oijoo https://github.com/librorum/scoop-oijoo
scoop install oijoo/oijoo
```

업데이트는 앱의 업데이트 버튼(앱을 끄고 `scoop update oijoo`를 실행한 뒤 다시 켬)이나 `scoop update oijoo`로 합니다.
설치 정보(`bucket/oijoo.json`)는 새 버전을 올릴 때 Oijoo 저장소의 `scripts/update-scoop.sh`가 갱신합니다.
